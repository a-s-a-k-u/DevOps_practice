\# AGENTS.md — инструкция для ИИ-агента



Стенд курса «Технологии DevOps», вариант 75.

Файл заводится в ЛР1 и дополняется в каждой работе.



\## Инварианты стенда



\- Два узла Debian 13: `node-1` (192.168.56.11) и `node-2` (192.168.56.12). Обращаться к ним \*\*только по именам\*\*, IP-адреса не хардкодить.

\- Вход по SSH \*\*только по ключу\*\*. Парольный вход отключён (`ssh\_pwauth: false`).

\- `sudo` у пользователя `student` запрашивает пароль. Пароли и приватные ключи в репозитории \*\*не хранятся\*\*.

\- Порты снаружи:

&#x20; - На \*\*обоих\*\* узлах: 22, 80, 443.

&#x20; - Только на \*\*node-1\*\*: 2222, 8443, 5050, 6443.

&#x20; - Новый порт наружу не открывать без явного указания.

\- Пользователь `app` — для приложения, без `sudo`, без пароля, без входа по SSH.

\- Docker работает без `sudo` (пользователь `student` в группе `docker`).

\- Всё, что меняется на узлах, \*\*описывается кодом в этом репозитории\*\*. Ручная правка на узле — дрейф, её нужно перенести в код.

\- Инструменты варианта фиксированы на семестр: менять их нельзя.



\## Команды проверки



Список дополняется в каждой работе.



\- `ssh -i \~/.ssh/student\_key student@node-1 "hostname"` — узел доступен по ключу.

\- `ssh -i \~/.ssh/student\_key student@node-1 "docker run --rm hello-world"` — Docker работает без sudo.

\- `ssh -i \~/.ssh/student\_key student@node-1 "ping -c1 node-2"` — узлы видят друг друга по именам.

\- `nc -z -w2 node-2 8443` — порт node-1 на node-2 закрыт (должен быть отказ).

\- `bash scripts/check-stand.sh` — полная проверка стенда.



\*\*Правило:\*\* изменение считается готовым, только когда команда проверки отработала.



\## Запреты



\- \*\*Не передавать агенту секреты:\*\* приватные ключи, пароли, токены CI, содержимое `ansible-vault` и `.env`.

\- \*\*Не выполнять на узлах команды, которых нет в задании.\*\* Сначала показать правки, потом применять.

\- \*\*Не отключать проверки:\*\* TLS, подпись образов, гейты конвейера, защиту ветки.

\- \*\*Не работать агентом в namespace `prod`\*\* и в репозитории окружений без ревью.

\- \*\*Не коммитить сгенерированный код без чтения.\*\* Ответственность за содержимое репозитория несёт студент.

\- \*\*Не использовать тег `latest`\*\* для образов и версий.

\- \*\*Не коммитить артефакты сборки\*\* (`\*.iso`, `\*.vdi`, `\*.qcow2`) — только исходные файлы.

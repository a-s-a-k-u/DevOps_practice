# DevOps Infrastructure: Стенд для практики (НИЯУ МИФИ)

Репозиторий содержит инфраструктурный код (IaC) и конфигурацию для автоматического развертывания учебного стенда из двух виртуальных машин. Проект выполнен в рамках курса «Технологии DevOps».

##  Цель проекта
Отработка практических навыков работы с Linux, сетями и инструментами автоматизации. Стенд создается с нуля и не требует ручной настройки после первой загрузки (Zero-Touch Provisioning).

##  Архитектура стенда

| Узел | Роль | ОС | RAM | vCPU | Диск |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **node-1** | Master / GitLab / Runner | Debian 13 (trixie) | 8 ГБ | 4 | 40 ГБ |
| **node-2** | Worker / App | Debian 13 (trixie) | 4 ГБ | 2 | 20 ГБ |

**Сеть:**
*   **Host-only (VirtualBox)**: `192.168.56.0/24` — для связи между узлами и хост-машиной.
*   **NAT (VirtualBox)**: для доступа виртуальных машин в интернет (скачивание пакетов).

## Реализованные задачи (ЛР1)

1.  **Автоматизация первичной настройки:** Использован `cloud-init` (файлы `user-data`, `meta-data`, `network-config`).
2.  **Сетевая конфигурация:** 
    *   Настроены статические IP-адреса (`192.168.56.11` и `192.168.56.12`).
    *   Настроен локальный DNS через `/etc/hosts` (резолвинг имен `node-1`, `node-2`, `dev.node-1`, `prod.node-1`).
3.  **Безопасность и доступ:**
    *   Вход по SSH **только по ключам** (парольная аутентификация отключена).
    *   Созданы пользователи: `student` (с sudo) и `app` (без sudo, для приложений).
    *   Настроен firewall **UFW** по принципу «deny by default». Открыты только необходимые порты (22, 80, 443 и специфичные для node-1).
4.  **Контейнеризация:** Установлен Docker CE. Пользователь `student` добавлен в группу `docker` (запуск контейнеров без `sudo`).
5.  **Мониторинг и проверка:** Написан Bash-скрипт `check-stand.sh`, который автоматически проверяет доступность узлов, работу Docker и состояние портов.
